## 🚀 Proyectos destacados

### 🏫 Sistema de Reservas de Aulas

**React · Node.js · Express · Keycloak · Docker · Jest**

Aplicación web Full Stack desarrollada como proyecto académico grupal de Desarrollo de Software en la UTN Córdoba.

Permite gestionar reservas de aulas mediante autenticación y control de acceso según roles.

**Características principales:**
- Creación, edición y cancelación de reservas.
- Autenticación y autorización con Keycloak.
- Administración de solicitudes y aprobaciones.
- Validaciones de reglas de negocio.
- Historial de operaciones.
- Pruebas automatizadas del backend.

🔗 [Ver repositorio](https://github.com/JazzRearte/sistema-reservas-aulas)

---

### 📦 Gestión de Artículos Fullstack

**React · Vite · Node.js · Express · API REST**

Aplicación web para administrar un catálogo de artículos mediante una interfaz desarrollada con React y conectada a un backend con Node.js y Express.

**Características principales:**
- Operaciones CRUD de artículos.
- Consulta, búsqueda y filtrado.
- Formularios reutilizables.
- Navegación con React Router.
- Comunicación frontend-backend mediante API REST.

🔗 [Ver repositorio](https://github.com/JazzRearte/gestion-articulos-fullstack)

---

### 🎓 Sistema de Gestión Académica

**HTML · JavaScript · Node.js · Express · Sequelize · SQLite**

Sistema web para administrar alumnos, cursos e inscripciones, desarrollado como proyecto académico.

**Características principales:**
- Gestión de alumnos y cursos.
- Inscripciones con validación de cupos.
- Prevención de inscripciones duplicadas.
- Relaciones entre entidades mediante Sequelize.
- Transacciones para mantener la consistencia de datos.

🔗 [Ver repositorio](https://github.com/JazzRearte/sistema-gestion-academica)
